# Medical Chatbot (RAG-Powered)

An intelligent medical assistant powered by FastAPI, LangChain, Google Gemini, Pinecone vector search, and Supabase PostgreSQL.

### Features
- 🩺 **Retrieval-Augmented Generation (RAG)**: Searches verified medical literature before answering.
- ⚡ **FastAPI Backend**: Asynchronous API endpoints with session tracking.
- 🐘 **Supabase PostgreSQL**: Persistent user profiles, chat history, and sources storage.
- 🔐 **Dual Authentication**: Google OAuth 2.0 (GIS) + Custom Secure JWT Cookies.
- 🎨 **Modern Responsive UI**: Clean medical interface with live character limits, collapsible sources, and conversation drawer.
